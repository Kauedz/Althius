# 05: Biblioteca de padrões coletivos aprovados

**What to build:** um processo do app que, dos Workspaces que contribuem, extrai padrões por segmento, canal e resultado,
anonimiza, exige amostra mínima e revisão humana, e só então os oferece ao Hermes como evidência para outros Workspaces
do mesmo segmento.

**Blocked by:** 03: Medir o resultado de cada mensagem; 04: Permissão para contribuir.

**Status:** needs-info

- [ ] O padrão guarda segmento, canal, abordagem, amostra e janela; nunca nome, contato, empresa ou trecho literal.
- [ ] Amostra mínima e revisão humana antes de publicar; quem aprovou fica registrado.
- [ ] O Hermes recebe só os padrões do segmento do pedido, como evidência, não como regra.
- [ ] Nenhuma conversa bruta numa busca global; nenhum Workspace lê dado privado de outro.
